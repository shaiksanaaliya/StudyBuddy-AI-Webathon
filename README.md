# StudyBuddy AI — Webathon 2026

A responsive, student-focused study dashboard prototype built with HTML, CSS, and vanilla JavaScript.

## Features
- Dashboard with task and quiz progress
- Notes helper that creates a basic extractive summary and keyword list
- Practice quiz generated from pasted notes using simple keyword rules
- Study planner with completion checkboxes and browser localStorage
- Responsive layout for laptop and mobile screens
- No API key, server, or paid service required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Use the Notes helper, Quiz practice, and Study planner tabs.

For best local development experience, open the folder in VS Code and use the Live Server extension, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Project structure
- `index.html` — page structure
- `styles.css` — responsive styling
- `script.js` — app navigation and features
- `docs/` — documentation, cover letter, and presentation are supplied separately in the submission bundle

## Important limitations
This is an educational prototype, not a connected generative-AI product. Summary and quiz behaviour uses browser-side rules and keyword extraction. Tasks and best score are saved only in the current browser. No user account, cloud sync, or external AI service is used.
